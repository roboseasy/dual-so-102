# 개발 · 시험

## 구조

```text
src/lerobot_robot_dual_so102/
├── __init__.py   # 등록 설정 · 장치 클래스 export (LeRobot 자동 발견 진입점)
├── arm.py        # 7축 버스(재시도 · 미러) + 단팔 팔로워 · 리더 (등록 안 함)
├── config.py     # dual_so102_follower · dual_so102_leader · dual_so102_client 설정 + host 설정
├── dual.py       # 양팔 팔로워 · 리더 (공식 BiSOFollower · BiSOLeader 상속)
├── wire.py       # host ↔ client 전송 형식 (JSON + base64 JPEG)
├── client.py     # PC client (수신 스레드 · 관측 끊김 · 카메라 검증)
├── host.py       # dual-so102-host
└── tools.py      # dual-so102-check · dual-so102-setup-motors
tests/            # 시리얼을 열지 않는 가짜 버스 시험 (tests/fake_bus.py)
```

## 설계 메모

- **공식 클래스 상속.** 양팔 · 단팔 모두 LeRobot 공식 `SOFollower` · `SOLeader` · `BiSOFollower` · `BiSOLeader` 를
  상속하고 모터 버스만 7축(ID 1~7, 그리퍼 0~100)으로 바꿉니다. 연결 · 보정 · 관측 · 명령은 공식 코드 그대로입니다.
- **등록 이름은 셋.** `dual_so102_follower` · `dual_so102_leader` · `dual_so102_client` 만 등록합니다.
  `so102_*` · `bi_so102_*` 를 등록하지 않아 기존 코드를 덮어쓴 LeRobot · `so-102` 플러그인과 공존합니다.
  단팔 클래스의 `name` 은 `so102_follower` · `so102_leader` 라 보정 파일 위치가 기존과 같습니다.
- **양팔 생성자.** 공식 `BiSOFollower.__init__` 은 팔을 6축 `SOFollower` 로, id 를 `{id}_left/_right` 로 고정해
  만들어 미러의 좌우 교체를 표현할 수 없습니다. 그래서 같은 규칙으로 팔을 직접 만듭니다. id 가 없으면 두 팔이
  `None.json` 을 같이 덮어쓰므로 시작할 때 막습니다.
- **미러.** 연결할 때 버스 보정 사본에만 1 · 5 · 6번 `drive_mode=1` 을 넣고, 도 단위에서도 부호를 뒤집습니다.
  Feetech `write_calibration` 은 `drive_mode` 를 모터에 쓰지 않으므로 사본이 모터나 파일로 새지 않습니다.
- **client.** 수신 스레드가 관측 도착 시각을 찍습니다. 호출할 때 소켓을 비우는 방식은 PC 루프가 멈춘 사이 host 가
  죽으면 멈추기 전 메시지를 새것으로 착각합니다 (`test_host_died_during_pause_raises`).
- **host.** 포트를 먼저 잡고(다른 host 가 돌면 팔을 건드리기 전에 멈춤) 팔을 연결합니다. SIGTERM · SIGHUP 을
  Ctrl+C 와 같이 정리합니다.

## 시험

하드웨어 없이 돕니다. 공식 LeRobot 명령 · 파서 · 제어 루프를 그대로 돌리고 시리얼만 가짜로 바꿉니다
(`so-102` 의 `tests/test_native_plugin.py` 방식). pytest 없이 표준 `unittest` 로 돕니다.

```bash
python -m unittest discover -s tests -v
```

PC 는 `conda run -n lerobot python -m unittest discover -s tests -v`, Pi 는 레포 폴더에서 venv 가 켜진 채 실행합니다.
깨끗한 설치 확인은 LeRobot 0.6.0 만 있는 새 환경에서 `pip install -e ".[dual-so-102]"` 후 같은 명령을 돌립니다.

문서의 명령(`lerobot-*` · `dual-so102-host`)은 `tests/test_repo.py` 가 공식 설정 클래스로 읽어 봅니다. 문서를 고치면
이 시험이 옵션 이름 · 타입 오타를 잡습니다.
