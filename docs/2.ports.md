# USB 포트 고정

USB 를 다시 꽂으면 `/dev/ttyACM0` · `/dev/ttyACM1` 번호가 바뀔 수 있습니다. udev 규칙으로 바뀌지 않는 별칭을 만듭니다.

| 별칭 | 장치 | 기준 |
|---|---|---|
| `/dev/so102_follower_left` · `/dev/so102_follower_right` | 팔로워 보드 (12 V) | 보드 USB serial |
| `/dev/so102_leader_left` · `/dev/so102_leader_right` | 리더 보드 (5 V) | 보드 USB serial |
| `/dev/cam_top` · `/dev/cam_left` · `/dev/cam_right` | 카메라 (Pi) | 꽂은 USB 위치 |

예시 규칙: [config/99-dual-so102.rules.example](../config/99-dual-so102.rules.example). 그 컴퓨터에 꽂히는 장치 줄만
남겨도 됩니다 (Pi 분리 구성: Pi 는 팔로워 2 + 카메라 3, PC 는 리더 2).

## 1. 보드 역할 · 좌우 확인

```bash
dual-so102-check
```

포트마다 역할(팔로워 12 V · 리더 5 V) · 모터 ID · 판정을 한 줄씩 적습니다. 읽기만 하므로 팔이 움직이거나 토크가
바뀌지 않습니다. host · 텔레옵 · 녹화가 쓰는 중인 포트는 열지 않고 `사용 중 (pid N)` 으로 알려 줍니다 (같이 열면
그 프로그램이 서보 응답을 놓쳐 끝나고 토크가 풀리기 때문입니다). 그 프로그램을 끄고 다시 실행합니다.

왼팔 · 오른팔은 알 수 없으므로 한 팔의 USB 를 뽑고 다시 실행해 사라진 포트를 봅니다
(공식 `lerobot-find-port` 도 같은 방법입니다).

## 2. 보드 serial 읽기

```bash
udevadm info --query=property --name=/dev/ttyACM0 | grep ID_SERIAL_SHORT
udevadm info --query=property --name=/dev/ttyACM1 | grep ID_SERIAL_SHORT
```

## 3. 규칙 작성 · 적용

```bash
cp config/99-dual-so102.rules.example config/99-dual-so102.rules
nano config/99-dual-so102.rules
sudo install -m 0644 config/99-dual-so102.rules /etc/udev/rules.d/99-dual-so102.rules
sudo udevadm control --reload-rules
sudo udevadm trigger
```

`REPLACE_*_SERIAL` 을 2절에서 읽은 값으로 바꿉니다. 값은 보드마다 달라야 합니다. `config/99-dual-so102.rules` 는
장비마다 다른 설정이라 Git 에서 뺍니다 (`.gitignore`). 로봇을 제어하는 프로그램을 끝낸 뒤 USB 를 다시 꽂고 확인합니다.

```bash
ls -l /dev/so102_*
```

## 4. 카메라 (Pi)

USB 카메라는 serial 이 없어 **꽂은 USB 위치**로 구분합니다. 카메라를 다른 포트에 꽂으면 별칭이 다른 카메라를
가리키므로, 포트에 이름표를 붙여 두고 이 표를 키트마다 적어 둡니다.

```bash
v4l2-ctl --list-devices
udevadm info --attribute-walk --name=/dev/video0 | grep -m1 'KERNELS=="[0-9]'
```

| 카메라 | 별칭 | KERNELS (키트 1호 실측, Pi 4) |
|---|---|---|
| 탑뷰 | `/dev/cam_top` | `1-1.3:1.0` |
| 왼쪽 손목 | `/dev/cam_left` | `1-1.4.4:1.0` (1-1.4 에 꽂은 허브의 4번) |
| 오른쪽 손목 | `/dev/cam_right` | `1-1.4.3:1.0` (같은 허브의 3번) |

`REPLACE_CAM_*_KERNELS` 를 이 값으로 바꿉니다. `ATTR{index}=="0"` 은 카메라마다 생기는 두 노드 중 영상 노드만 고릅니다.

## 5. serial 이 같거나 없는 보드

serial 로 구분할 수 없으면 카메라처럼 꽂은 USB 위치(`ID_PATH`)로 규칙을 만듭니다. 그 대신 보드를 늘 같은 포트에 꽂아야 합니다.

```bash
udevadm info --query=property --name=/dev/ttyACM0 | grep ID_PATH=
```

```text
SUBSYSTEM=="tty", ENV{ID_PATH}=="pci-0000:00:14.0-usb-0:1:1.0", SYMLINK+="so102_leader_left", GROUP="dialout", MODE="0660"
```

## 6. Physical Labs 앱이 만든 리더 별칭

Physical Labs 앱으로 설정한 PC 에는 리더 별칭 `/dev/bi_so102_leaders_left` · `/dev/bi_so102_leaders_right` 가 이미
있습니다. 이 이름을 `--teleop.left_arm_config.port` · `--teleop.right_arm_config.port` 에 그대로 써도 됩니다.

## 7. 별칭 없이

별칭을 만들지 않았다면 `/dev/ttyACM0` 처럼 실제 경로나 `/dev/serial/by-id/...` 를 줍니다.
`--robot.id` · `--teleop.id` 는 포트와 상관없는 보정 파일 이름이므로 늘 같게 둡니다.

## 8. 권한

```bash
id -nG
sudo usermod -aG dialout "$USER"
```

`dialout` 이 없으면 넣은 뒤 다시 로그인합니다.
