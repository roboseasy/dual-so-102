# 사용법

설치 → 모터 ID → 포트 → 보정 → 텔레오퍼레이션 → 녹화 → 학습 → 추론 순서입니다.
명령은 모두 LeRobot v0.6.0 공식 명령이고, 로봇 타입만 `dual_so102_*` 를 씁니다.

## 1. 구성

| 구성 | 팔로워 양팔 · 카메라 | 리더 양팔 | 로봇 타입 |
|---|---|---|---|
| PC 직결 | PC | PC | `--robot.type=dual_so102_follower` |
| Pi 분리 | Pi (`dual-so102-host`) | PC | PC 는 `--robot.type=dual_so102_client`, Pi 는 host |

리더는 언제나 `--teleop.type=dual_so102_leader` 입니다. Pi 분리 구성은 [Pi 분리 구성](3.pi.md)을 봅니다.

## 2. 설치

PC 는 LeRobot v0.6.0 이 설치된 conda 환경에 더합니다. extra `dual-so-102` 는 녹화(dataset) · 시각화(rerun)를
함께 설치합니다.

```bash
conda activate lerobot
cd ~
git clone https://github.com/roboseasy/dual-so-102.git
cd dual-so-102
pip install -e ".[dual-so-102]"
```

Pi 는 host 에 필요한 기본 의존성만 설치합니다 (`pip install -e .`). 새 Pi 준비는 [Pi 분리 구성](3.pi.md) 1절에 있습니다.

시리얼 포트 권한이 없으면 `dialout` 그룹에 넣고 다시 로그인합니다.

```bash
sudo usermod -aG dialout "$USER"
```

## 3. 새 팔의 모터 ID 설정

조립한 팔의 모터는 처음에 ID 가 모두 1 입니다. 팔마다 한 번 실행합니다 (팔 4개면 4번).
안내가 나오면 **그 모터 하나만** 보드에 연결하고 Enter 를 누릅니다. 그리퍼(7) → wrist_roll(6) → wrist_yaw(5)
→ wrist_flex(4) → elbow_flex(3) → shoulder_lift(2) → shoulder_pan(1) 순서입니다.

```bash
dual-so102-setup-motors --role follower --port /dev/ttyACM0
dual-so102-setup-motors --role leader --port /dev/ttyACM1
```

공식 `lerobot-setup-motors` 는 v0.6.0 에서 플러그인 타입을 받지 않아 이 명령을 따로 둡니다.
끝나면 모터를 모두 이어 연결하고 `dual-so102-check` 로 `ids=1..7 OK` 를 확인합니다.

## 4. 포트

[USB 포트 고정](2.ports.md)으로 `/dev/so102_follower_left` · `/dev/so102_follower_right` ·
`/dev/so102_leader_left` · `/dev/so102_leader_right` 를 만듭니다. 별칭 없이 `/dev/ttyACM*` 를 직접 줘도 됩니다.

## 5. 보정

```bash
lerobot-calibrate \
  --robot.type=dual_so102_follower \
  --robot.id=bi_so102 \
  --robot.left_arm_config.port=/dev/so102_follower_left \
  --robot.right_arm_config.port=/dev/so102_follower_right
```

왼팔, 오른팔 순서로 진행합니다. 팔마다 나오는 안내 (공식 LeRobot 문구):

1. 보정 파일이 이미 있으면 `Press ENTER to use provided calibration file ... or type 'c'` —
   Enter 는 파일을 모터에 다시 쓰고, `c` 는 새로 보정합니다.
2. `Move ... to the middle of its range of motion and press ENTER` — 모든 관절을 가동 범위 가운데에 두고 Enter.
3. `Move all joints except 'wrist_roll' sequentially through their entire ranges of motion` —
   wrist_roll 을 뺀 관절을 끝에서 끝까지 하나씩 움직이고 Enter. wrist_roll 은 한 바퀴 전체(0~4095)로 둡니다.

리더도 같은 방법입니다.

```bash
lerobot-calibrate \
  --teleop.type=dual_so102_leader \
  --teleop.id=bi_so102_leader \
  --teleop.left_arm_config.port=/dev/so102_leader_left \
  --teleop.right_arm_config.port=/dev/so102_leader_right
```

- `--robot.id` 를 빠뜨리면 바로 오류로 멈춥니다. 공식 양팔 클래스는 id 가 없으면 두 팔이 같은 `None.json` 을
  덮어쓰기 때문입니다.
- 보정 파일 위치: `~/.cache/huggingface/lerobot/calibration/robots/so102_follower/<id>_{left,right}.json`,
  리더는 `.../teleoperators/so102_leader/<id>_{left,right}.json`. 기존 양팔 코드 · `so-102` 플러그인과 같은
  곳이라 기존 파일을 그대로 씁니다.

## 6. 텔레오퍼레이션 (PC 직결)

```bash
lerobot-teleoperate \
  --robot.type=dual_so102_follower \
  --robot.id=bi_so102 \
  --robot.left_arm_config.port=/dev/so102_follower_left \
  --robot.right_arm_config.port=/dev/so102_follower_right \
  --teleop.type=dual_so102_leader \
  --teleop.id=bi_so102_leader \
  --teleop.left_arm_config.port=/dev/so102_leader_left \
  --teleop.right_arm_config.port=/dev/so102_leader_right \
  --display_data=false
```

리더를 팔로워와 비슷한 자세로 맞춘 뒤 실행합니다. 리더 왼팔이 팔로워 왼팔을 움직입니다.
실행 직후에는 천천히 움직여 좌우 대응부터 확인합니다 (포트를 바꿔 꽂으면 팔이 엇갈려 움직입니다).

## 7. 녹화 · 재생 (PC 직결)

PC 에 꽂은 카메라는 `lerobot-find-cameras opencv` 로 번호를 찾습니다.

```bash
HF_USER=my_name  # Hugging Face 아이디 (올리지 않으면 아무 이름)

lerobot-record \
  --robot.type=dual_so102_follower \
  --robot.id=bi_so102 \
  --robot.left_arm_config.port=/dev/so102_follower_left \
  --robot.right_arm_config.port=/dev/so102_follower_right \
  --robot.cameras='{"cam_top": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}, "cam_left": {"type": "opencv", "index_or_path": 2, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}, "cam_right": {"type": "opencv", "index_or_path": 4, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}}' \
  --teleop.type=dual_so102_leader \
  --teleop.id=bi_so102_leader \
  --teleop.left_arm_config.port=/dev/so102_leader_left \
  --teleop.right_arm_config.port=/dev/so102_leader_right \
  --dataset.repo_id=${HF_USER}/dual_so102_pick \
  --dataset.single_task="블록을 상자에 넣기" \
  --dataset.num_episodes=10 \
  --dataset.episode_time_s=30 \
  --dataset.reset_time_s=10 \
  --dataset.push_to_hub=false

lerobot-replay \
  --robot.type=dual_so102_follower \
  --robot.id=bi_so102 \
  --robot.left_arm_config.port=/dev/so102_follower_left \
  --robot.right_arm_config.port=/dev/so102_follower_right \
  --dataset.repo_id=${HF_USER}/dual_so102_pick \
  --dataset.episode=0
```

- 데이터셋 키: 관절 14개(`left_shoulder_pan.pos` …) + 카메라. 카메라 키는 `--robot.cameras` 의 이름 그대로입니다.
- 데이터셋의 `robot_type` 은 `dual_so102_follower` 또는 `dual_so102_client` 로 기록됩니다. 타입이 다른 데이터셋에
  `--resume` 으로 이어 찍을 수 없습니다 (기존 양팔 코드의 `bi_so102_*` 데이터셋 포함). 학습 · 추론은 키가 같아 영향이 없습니다.

## 8. 학습

학습은 공식 `lerobot-train` 을 그대로 씁니다. 필요한 LeRobot extra 를 먼저 설치합니다.

```bash
pip install "lerobot[training]==0.6.0"
lerobot-train \
  --dataset.repo_id=${HF_USER}/dual_so102_pick \
  --policy.type=act \
  --policy.device=cuda \
  --policy.push_to_hub=false \
  --output_dir=outputs/train/act_dual_so102 \
  --job_name=act_dual_so102 \
  --wandb.enable=false
```

SmolVLA 는 `pip install "lerobot[smolvla]==0.6.0"` 후 `--policy.path=lerobot/smolvla_base` 로 시작합니다.

## 9. 추론

v0.6.0 에서 추론은 `lerobot-rollout` 입니다 (`lerobot-record` 는 리더가 있어야 합니다).
카메라 이름 · 크기는 녹화 때와 같아야 합니다.

```bash
lerobot-rollout \
  --strategy.type=base \
  --policy.path=outputs/train/act_dual_so102/checkpoints/last/pretrained_model \
  --robot.type=dual_so102_follower \
  --robot.id=bi_so102 \
  --robot.left_arm_config.port=/dev/so102_follower_left \
  --robot.right_arm_config.port=/dev/so102_follower_right \
  --robot.cameras='{"cam_top": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}, "cam_left": {"type": "opencv", "index_or_path": 2, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}, "cam_right": {"type": "opencv", "index_or_path": 4, "width": 640, "height": 480, "fps": 30, "fourcc": "MJPG"}}' \
  --task="블록을 상자에 넣기" \
  --duration=60
```

첫 실행은 `--duration` 을 짧게 두고 `Ctrl+C` 를 누를 준비를 한 채 지켜봅니다.
Pi 분리 구성이면 로봇 부분을 `--robot.type=dual_so102_client --robot.remote_ip=...` 와 카메라 설정으로 바꿉니다.

## 10. 미러 모드 (팔로워가 나를 마주 보게)

팔로워를 리더와 마주 보게 두고 거울처럼 조종합니다. **팔로워 쪽에만** `--robot.mirror_mode=true` 를 더합니다
(PC 직결이면 `dual_so102_follower` 명령, Pi 분리면 `dual-so102-host`). 리더 · client 명령은 그대로입니다.

켜면 바뀌는 것:

- 모터 1 · 5 · 6 (`shoulder_pan` · `wrist_yaw` · `wrist_roll`) 의 부호를 뒤집습니다. 보정 사본에서만
  `drive_mode=1` 로 바꾸므로 **보정 파일은 바뀌지 않습니다.** 도 단위(기본)에서도 적용됩니다.
- 좌우를 바꿉니다. 리더 왼팔(`left_*`)이 팔로워 오른팔을 움직입니다. 포트 · 보정 파일(`<id>_right.json`) ·
  팔별 카메라(`--robot.right_arm_config.cameras`)가 짝으로 바뀌므로 다시 보정하지 않습니다.
- 시작 로그에 `Mirror mode: left_* -> <포트> (<id>_right), right_* -> <포트> (<id>_left)` 가 찍힙니다.

주의:

- 반전은 보정 범위 가운데를 기준으로 합니다. 시작 전에 리더를 팔로워와 마주 보는 자세로 맞춥니다.
- 미러로 녹화한 데이터는 1 · 5 · 6번 부호와 좌우가 평소와 반대입니다. 평소 데이터와 한 데이터셋에 섞지 않고,
  추론도 `--robot.mirror_mode=true` 로 합니다.
- 최상위 `--robot.cameras` 의 이름은 바뀌지 않습니다 (`cam_left` 는 계속 물리적 왼쪽 카메라).

## 11. 안전

- 끝내면 토크가 풀립니다. 팔을 받친 채 끝냅니다.
- 실행 전 로봇 주변을 치우고, `Ctrl+C` 를 바로 누를 수 있게 합니다.
- 전원: 리더 5 V, 팔로워 12 V. 전압 오류가 반복되면 어댑터와 데이지 체인 커넥터부터 봅니다.
- `--robot.max_relative_target` 은 기본값(제한 없음)으로 둡니다. 5 로 두면 30 Hz 에서 150°/s 로 잘리고
  명령마다 현재 위치를 다시 읽어 팔로워가 둔하게 따라옵니다.
